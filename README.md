
# 🚀 Open Course Assignment

## 📌 Project Overview
This is a **React.js Proof of Concept (PoC)** project demonstrating the use of **React Helmet** for managing metadata dynamically. The project provides a clean UI and a structured approach to implementing SEO improvements in React applications.

---

## 🛠️ Tech Stack
- ⚛ **React.js** – Component-based UI library  
- 🏗 **React Helmet** – Manage document head metadata  
- 🎨 **HTML, CSS, JavaScript** – Frontend styling and scripting  

---


## 📦 Installation & Setup
Follow these steps to set up the project locally:

### **1️⃣ Clone the Repository**
```sh
git clone https://github.com/AkhileshPokale30/open-course-assignment.git
```

### **2️⃣ Install Dependencies**
Navigate into the project folder and install required dependencies:
```sh
cd open-course-assignment
cd my-app
npm install
npm install react-scripts --save
npm install react-icons
```

### **3️⃣ Start the Development Server**
Run the following command to start the app:
```sh
npm start
```
Your React app will be available at **http://localhost:3000/**.
